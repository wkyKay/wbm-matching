## 保存位置与文件含义

服务器根目录为 `/data/wangkaiyan2024/compared_methods/`；`/data/wangkaiyan2024/wbm-matching` 是同一目录的符号链接。

- 每项正式结果的路径，以主项目 [登记表](https://github.com/wkyKay/wbm-region-retrieval/blob/main/results_catalog/registry.csv) 的 `remote_path` 为准。WBBS test、WMHD valid/test 使用已完成的 `_r2` 来源，不能混入早期未完成目录。
- WaPIRL 训练在 `artifacts/wapirl_f_aligned_v1/`，评价在 `artifacts/wapirl_valid_v1/`、`artifacts/wapirl_test_v1/`。
- 七方法跨组合在 `artifacts/cross_coverage_seven_test_20261111_v1/`。

| 文件 | 含义 |
|---|---|
| `completed.json`、`evaluation_manifest.json` | 完成标记、配置、协议、源码及来源身份；读取时还需核对引用文件 |
| `<split>/metrics.json` | exact 汇总；逐 query、逐类别另存 CSV |
| `<split>/coverage_metrics.json` | coverage 汇总；部分历史后处理是独立目录，以登记路径为准 |
| `<split>/rankings.csv` | 同一评价排名的 Top-500，不是全库排行 |
| 主项目 `results_catalog/` | 唯一登记表、来源快照和自动汇总；轻量文件随 Git 同步 |

模型、缓存、原始数据和排名产物不随 Git 发布，也未在本次整理中移动。[历史索引](history/20261116/README.md)保留 WaPIRL、跨组合和验证原记录，标明适用时间与产物所在端；smoke 和某次测试通过数不能当作当前正式模型成绩。

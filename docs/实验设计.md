# 实验设计

六个方法共享同一份去重划分、query/gallery 和评价代码，各自保留原方法的表示与打分方式。

| 方法 | 怎么检索 | 训练与选择规则 |
|---|---|---|
| [Wu](../methods/wu/README.md) | 116 维手工特征粗筛，再用 NCC 排序 | 无训练；粗筛不改变评价分母 |
| [Yu](../methods/yu/README.md) | 分类 CNN、PCA、十值编码，比较编码差异 | 监督训练；PCA 和编码缩放只拟合 train |
| [WBBS](../methods/wbbs/README.md) | 张量投票和点描述子，比较加权最佳伙伴 | 无训练 |
| [Nakazawa](../methods/nakazawa/README.md) | 256 维 sigmoid 特征按 ≥0.5 二值化，Hamming 检索 | 监督训练 10 epoch，固定最后一轮，不按 valid loss 选模 |
| [WMHD](../methods/wmhd/README.md) | mountain 密度和方向性加权 Hausdorff 距离 | 无训练 |
| [WaPIRL](../methods/wapirl/README.md) | 整图三通道 ResNet18 h512，截断余弦 | 与 F 对齐的自监督适配，100 epoch，冻结 best_nce |

Yu 和 Nakazawa 是独立方法，不能混用网络、编码或选模规则。Nakazawa 原文的 22 类适配为当前 37 类；数据没有每 die 的缺陷事件计数，使用缺陷占用图，不能声称恢复了原始缺陷密度。WBBS、WMHD 中未公开的参数同样在方法 README 标明。

统一评价只读取训练来源，不隐式训练。普通 test 的六方法均已完成；跨组合另加入旧 F 形成七方法。主项目当前 cc8 的方法和融合说明见 [主项目实验设计](https://github.com/wkyKay/wbm-region-retrieval/blob/main/doc/%E5%AE%9E%E9%AA%8C%E8%AE%BE%E8%AE%A1.md)。

这里比较的是当前实现与明确披露的适配版本，不宣称完全恢复了作者未公开的源码。监督、自监督和无训练方法要分别标明，不能把差异归因于单一模块。

## 实验设计

六方法共享去重划分、query/gallery 和评价代码，各自保留原方法的表示与打分方式。

| 方法 | 怎么检索 | 训练与选择规则 |
|---|---|---|
| [Wu](../methods/wu/README.md) | 116 维手工特征粗筛，NCC 重排 | 无训练；粗筛不改变评价分母 |
| [Yu](../methods/yu/README.md) | 分类 CNN、PCA、十值编码 | 监督训练；PCA 和编码缩放只拟合 train |
| [WBBS](../methods/wbbs/README.md) | 张量投票、点描述子和加权最佳伙伴 | 无训练 |
| [Nakazawa](../methods/nakazawa/README.md) | 256 维 sigmoid 特征按 ≥0.5 二值化，Hamming 检索 | 监督训练 10 epoch，固定最后一轮，不按 valid loss 选模 |
| [WMHD](../methods/wmhd/README.md) | mountain 密度和方向性加权 Hausdorff 距离 | 无训练 |
| [WaPIRL](../methods/wapirl/README.md) | 整图三通道 ResNet18 h512，截断余弦 | 与 F 对齐的自监督适配，100 epoch，冻结 best_nce |

Yu 和 Nakazawa 独立复现，不混用网络或选模规则。Nakazawa 原文 22 类适配为当前 37 类；数据没有每 die 的缺陷事件计数，输入用缺陷占用图，不声称恢复了缺陷密度。WBBS、WMHD 未公开的参数也在各方法 README 标明。

比较时区分监督、自监督和无训练方法，不把当前适配成绩直接等同于原论文。主项目当前 F 的定义见[主项目实验设计](https://github.com/wkyKay/wbm-region-retrieval/blob/main/doc/项目说明.md#实验设计)。

## 数据与评价

Mixed-WM38 原始 38,015 条按完整 0/1/2/3 像素精确去重，每组保留最小原始 ID；过滤 1,024 条冗余后有 35,991 张缺陷图和 1,000 张 Normal。缺陷图按 37 种完整标签组合分层，seed=2026。

| 集合 | 图像数 | query 数 | 每个 query 的候选数 |
|---|---:|---:|---:|
| train | 25,193 | — | — |
| valid | 3,599 | 固定 500 | 3,598 |
| test | 7,199 | 全部 7,199 | 7,198 |

每个 query 检索同集合全部其他图像，排除自身。Normal 不入缺陷检索库；Yu 检测器所需 Normal 按 seed=2026 分为 700/100/200，写入运行目录，尚未独立中央冻结。`sample_id` 是原始 NPZ 行号，不重新编号。

标签顺序为 center、donut、edge-loc、edge-ring、loc、near-full、scratch、random。清单位于 `protocol/deduplicated/`、`protocol/retrieval_v1/`，加载时检查哈希，不重划或覆盖；具体文件和生成规则见[协议说明](../protocol/README.md)。

用 Q、C 表示查询与候选标签集合，以下指标评价同一排名：

| 评价 | 相关性 | 指标 |
|---|---|---|
| exact | Q=C | Hit、Precision、Recall、AP/mAP |
| coverage | g=\|Q∩C\|/\|Q\| | MeanCoverage、Coverage-nDCG |
| FullCoverage | Q⊆C，允许额外标签 | FullCoverage 的 Hit、Precision、Recall、AP/mAP |

K=1、5、10、20、50、100、500。前 K 命中数为 H，完整候选库正样本数为 R：Hit 判断 H>0，Precision=H/K，Recall=H/R；AP 是各命中位置的 Precision 之和除以 R，mAP 是 query 的 AP 平均，分母不是 min(R,K)。MeanCoverage 是前 K 覆盖比例之和除以 K；nDCG 使用线性增益 g/log₂(rank+1)，理想排序取完整候选库。

缺位贡献零。R=0 的 query 不参加对应 Recall/AP 平均，但保留其他指标；IDCG=0 时不参加 nDCG 平均。报告总体、完整组合类别宏平均、单/混合及标签数量分组，不启用部分覆盖阈值 τ。实现见 [exact](../shared/exact_metrics.py)、[coverage](../shared/coverage_metrics.py)。

普通检索按方法分数排序，真实标签只用于评价；同分用固定 SHA-256 次序，Wu 另保留粗筛距离次排序键。仅保存 Top-500，不能称为完整排名；Wu 只对粗筛入选者做 NCC，但 Recall/AP 分母仍取完整候选库。

**跨组合协议**在粗筛和打分前额外排除完整标签组合相同的候选，只评价 coverage，是用标签定义候选资格的独立诊断。当前每 query 剩 6,999–7,170 个候选；999 个 query 无 FullCoverage 正样本，对应 Recall/AP 有效 query 为 6,200，其他指标使用全部 7,199 个 query。实现见 [cross_combination.py](../shared/cross_combination.py)，结果与普通协议分表。

## 如何运行

在仓库根目录使用原 PyTorch/CUDA 环境，依赖见 `requirements.txt`，默认数据为 `../data/wm38k/Wafer_Map_Datasets.npz`。公共实现位于 `shared/`，回归检查位于 `tests/`。

| 方法 | 训练入口 | 评价来源 |
|---|---|---|
| Wu、WBBS、WMHD | 无需训练 | 对应 `methods/<方法>/config.json` |
| Yu、Nakazawa | `methods/<方法>/<方法>.py --stage train` | `--source-run` 指向已完成训练目录 |
| WaPIRL | `methods/wapirl/wapirl.py`，没有 `--stage train` | 同上 |

训练可指定 `--config`、`--output-dir`、`--device cuda`；续训按方法 README 使用 `--resume`。统一评价只读来源，不隐式训练：

```text
python -u scripts/evaluate.py --config methods/<方法>/config.json \
  --split <valid或test> --output-dir artifacts/<本次评价的时间型run_id> \
  [--source-run <已完成训练目录>] [--device cuda] [--rank-workers <进程数>]
```

尖括号和方括号是待替换/选用项。参数先在 valid 确定，再显式运行 test；跨组合追加 `--exclude-exact` 并使用独立目录。smoke 换成该方法的 `smoke.json`，仅检查小 valid，不运行 test、不算正式成绩。

统一评价没有 `--resume`，输出目录必须是新的；失败产物保留，重跑另建目录。`--source-run` 不会绕过配置、源码或模型签名检查。新运行先落实下节的真实时间身份要求。

## 实验结果

| 结果组 | 完成状态与结论 |
|---|---|
| Wu、Yu、WBBS、Nakazawa、WMHD | 普通 test 有 exact/coverage；旧 valid 只有 exact，不补造 coverage |
| WaPIRL 整图适配 | 100 epoch 训练及 valid/test 已完成，best_nce 为第 100 轮 |
| 普通方法比较 | 总览列出的指标上，监督 Nakazawa 最高，WBBS 也高于当前 F；须注明监督信息差别 |
| WMHD | 当前适配成绩较低，不等于原论文方法无效 |
| 七方法跨组合 | 已完成；增加的是旧径向面积 F，不能替代当前 cc8 |

数值只维护在主项目[自动结果总览](https://github.com/wkyKay/wbm-region-retrieval/blob/main/results_catalog/CURRENT_RESULTS.md)和[指标长表](https://github.com/wkyKay/wbm-region-retrieval/blob/main/results_catalog/metrics.csv)，不再维护第二份手工成绩表。普通与跨组合结果分开解释。

## 保存与登记

服务器根目录为 `/data/wangkaiyan2024/compared_methods/`；旧 `wbm-matching` 是它的符号链接。GitHub 仓库名为 `wkyKay/wbm-matching`，分支 `main`。

| 内容 | 路径或含义 |
|---|---|
| 全部正式结果位置 | 主项目[登记表](https://github.com/wkyKay/wbm-region-retrieval/blob/main/results_catalog/registry.csv)的 `remote_path`；WBBS test、WMHD valid/test 使用已完成 `_r2` |
| WaPIRL | 训练在 `artifacts/wapirl_f_aligned_v1/`，评价在 `wapirl_valid_v1/`、`wapirl_test_v1/`，均位于 `artifacts/` 下 |
| 七方法跨组合 | `artifacts/cross_coverage_seven_test_20261111_v1/` |
| 完成与来源 | `completed.json`、`evaluation_manifest.json`；仍需核对引用文件哈希 |
| 指标与排名 | `<split>/metrics.json` 为 exact，`coverage_metrics.json` 为 coverage，`rankings.csv` 为 Top-500；另有逐 query/类别报告 |

部分历史 coverage 后处理使用独立目录，以登记路径为准。计时中 `ranking_total_seconds` 是各 query 耗时之和，`ranking_wall_seconds` 是排名阶段实际等待时间，含并行管理、评价和写出，不能互换。

新训练和每次独立评价分别保存真实启动时间型 `run_id=YYYYMMDDTHHMMSS+0800__稳定语义key`、带时区的 `started_at`；同一排名的 exact/coverage 共用身份。**登记器目前对历史结果使用完成标记 mtime；接入第一项新实验前须支持读取真实时间身份，不能静默回退。**

完成后核对产物，更新相邻主项目唯一的 `results_catalog/sources.json`，在服务器主项目根目录运行 `python3 results_catalog/build.py collect --workspace /data/wangkaiyan2024` 和 `python3 results_catalog/build.py check`。随后更新本页简短结论，同步两仓库本地、服务器和 GitHub。细则见 [AGENTS.md](../AGENTS.md)。模型、数据、缓存和排名原位保留，不随 Git 发布。

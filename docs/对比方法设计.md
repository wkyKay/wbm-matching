# 对比方法设计

整理日期：2026-11-17。本文区分原论文的方法与数据、本项目的适配和已经冻结的实验设置。成绩见[对比方法实验结果](对比方法实验结果.md)，公共评价和运行规则见[项目说明](项目说明.md)。

## 共同实验设计与数据集

- **目的**：在同一批混合缺陷晶圆上，比较手工整图特征、点集匹配、监督编码和自监督整图表示的检索效果。六种方法各保留自己的表示和打分，不因结果整理重新训练、调参或重复评价。
- **数据**：全部使用 MixedWM38，原始文件为工作区 `data/wm38k/Wafer_Map_Datasets.npz`。38,015 条记录按完整 0/1/2/3 像素精确去重，去掉 1,024 条冗余，得到 35,991 张缺陷图与 1,000 张 Normal；每组保留最小原始行 ID，标签冲突报错。
- **划分**：37 种完整缺陷标签组合分层，seed=2026，train/valid/test=25,193/3,599/7,199。八标签顺序固定为 center、donut、edge-loc、edge-ring、loc、near-full、scratch、random。Normal 不进入缺陷检索库；仅 Yu 检测器使用其中 train 700、valid 100，另 200 张留出。
- **检索池**：valid 固定 500 query、每 query 3,598 候选；test 全部 7,199 query、每 query 7,198 候选；排除自身。所有方法读取同一冻结清单，不能自行抽样或缩小图库。
- **评价**：同一排名分别计算 exact（完整标签组合相同）与 coverage（覆盖查询标签）；K=1/5/10/20/50/100。另有排除同组合候选的跨组合诊断，单独报告，不能混入普通 test。
- **监督与选择**：Yu、Nakazawa 使用类别监督；WaPIRL 使用自监督；Wu、WBBS、WMHD 不训练。测试标签只参与评价或显式跨组合候选资格过滤，不参与方法打分。不同输入、监督信息及优化次数意味着这些比较不是严格单因素消融。

| 方法 | 表示与排序 | 本项目训练／选模 | 原论文数据 → 本项目数据 |
|---|---|---|---|
| Wu | 116 维手工特征粗筛＋NCC 重排 | 无训练 | WM-811K → MixedWM38 37 组合 |
| Yu | CNN FC2→PCA256→十值编码→Hamming | 监督；最低 valid CE | WM-811K 八缺陷类 → MixedWM38 37 组合 |
| WBBS | 张量投票＋径向点描述＋加权最佳伙伴 | 无训练 | MixedWM38 合并后的 25 类 → 保留 37 组合 |
| Nakazawa | CNN sigmoid→256 位二值码→Hamming | 监督；10 epoch 最后一轮 | 合成密度图／真实工业图 → 缺陷占用图 |
| WMHD | mountain 密度＋方向性加权 Hausdorff | 无训练，W2-O1 | 制造数据模拟／调整图 → MixedWM38 |
| WaPIRL | 整图 ResNet18 h512→截断余弦 | 自监督；100 epoch，最低 valid NCE | WM-811K 分类预训练 → MixedWM38 整图检索适配 |

## 1. Wu：手工特征粗筛与相关性重排

- **论文**：Ming-Ju Wu、Jyh-Shing R. Jang、Jui-Long Chen，*Wafer Map Failure Pattern Recognition and Similarity Ranking for Large-Scale Data Sets*，IEEE TSM，28(1):1–12，2015（2014 在线发表）。[DOI](https://doi.org/10.1109/TSM.2014.2364237)。
- **原文实验与数据**：WM-811K，811,457 张真实晶圆。论文同时有 SVM 分类和 WMSR 相似性检索；这里采用无需训练的 WMSR。原文展示不同整图／显著区域融合权重的排序、不同图库规模下的搜索时间，不能把分类准确率当作检索准确率。
- **本项目流程**：原图和 3×3 中值滤波图各提取 40 维 Radon＋18 维几何／统计特征，共 116 维。欧氏距离粗筛最多 500 个候选，再用 `0.5×整图NCC＋0.5×最大面积显著区域NCC` 重排。
- **冻结设置与边界**：8 连通、52×52 NCC 画布，不训练 SVM、不用标签重排、不搜索旋转。粗筛 n=500、滤波及 Hough 等部分细节是实现约定；AP/Recall 分母仍用完整图库，不能把粗筛后的 500 张当作图库总数。
- **代码依据**：[Wu README](../methods/wu/README.md)。

## 2. Yu：监督 CNN 与十值编码检索

- **论文**：Naigong Yu、Qiao Xu、Honglu Wang，*Wafer Defect Pattern Recognition and Analysis Based on Convolutional Neural Network*，IEEE TSM，32(4):566–573，2019。[DOI](https://doi.org/10.1109/TSM.2019.2937793)。
- **原文实验与数据**：WM-811K 八种缺陷模式，另选 Normal 做检测。先检测／分类，再比较特征层和 PCA 维数，报告按类别的 Precision 与 Top-500 AP；原文检索池的部分表述含混，不套用为本项目协议。
- **本项目流程**：52×52 原图先做 9×9 中值滤波，再缩放至 224×224 三通道；分类器 FC2 的 1,024 维 sigmoid 特征只用 train 拟合 PCA256 和 min-max 缩放，编码为每维 0–9 的整数，以逐维不相等数量作为 Hamming 距离。
- **训练与选模**：检测器二分类、分类器 37 类；Adam 1e-4，检测／分类 batch=64/128，epoch 预算=10/80，分别取最低 valid CE。主比较使用 `global`，所有候选参与排序；预测类别门控仅是辅助变体，不混入本文六方法主表。
- **适配边界**：37 类替代原八类；颜色、裁剪幅度、十值 Hamming 的具体解释和 checkpoint 规则有明确补足约定。9×9 滤波可能消除细线，但本轮设置保持冻结；不继承为 Nakazawa 的预处理。
- **代码依据**：[Yu README](../methods/yu/README.md)。

## 3. WBBS：张量投票与加权最佳伙伴

- **论文**：Wang & Wang，*Similarity searching for fault diagnosis of defect patterns in wafer bin maps*，Computers & Industrial Engineering，2023。[DOI](https://doi.org/10.1016/j.cie.2023.109679)。
- **原文实验与数据**：MixedWM38 将 Edge-Loc/Edge-Ring 合并后形成 25 类、25,000 张图。单缺陷 query 以候选包含目标模式作为相关，另展示混合 query 排名；比较去噪与描述子等配置。原文 AP 不能直接与本项目 exact mAP 相比。
- **本项目流程**：所有缺陷点做闭式张量投票；stick、ball 同时低于各自最大值 0.32 倍才删除。使用归一化 `[stick,ball,rho]` 描述，统计互为最近邻点对 B，以 `B/min(N,M) × exp(-alpha×|N-M|/l)` 排序。
- **冻结设置**：无训练，alpha=5、mu=1，投票衰减 sigma_d=9 pixel²，l=2061。分数对称，不加入按 query 点数归一化的建议变体；保留本项目全部 37 组合，不合并 Edge 类。
- **适配边界**：sigma_d、一次投票、归一化范围及边界处理是披露的实现约定；无法声称已恢复作者全部默认参数。最近邻重复描述的同分会影响互为最近邻数量，不强制自相似度为 1。
- **代码依据**：[WBBS README](../methods/wbbs/README.md)。

## 4. Nakazawa：监督 CNN 二值编码检索

- **论文**：Nakazawa & Kulkarni，*Wafer Map Defect Pattern Classification and Image Retrieval Using Convolutional Neural Network*，IEEE TSM，2018。[DOI](https://doi.org/10.1109/TSM.2018.2795466)。
- **原文实验与数据**：28,600 张、22 类合成缺陷密度图，含混合模式；另用 1,191 张真实工业图验证。训练／验证／测试合成数据为 15,400/6,600/6,600；展示图像检索并报告 Top-1 检索错误率。
- **本项目流程**：输入为 `raw==2` 的单通道缺陷占用图，最近邻缩放至 286×400；三组卷积与池化，FC256 sigmoid 按 ≥0.5 二值化，按 256 位 Hamming 距离检索。37 类监督训练，不用 Yu 的滤波、检测器、PCA、十值编码或门控。
- **训练与选模**：10 epoch，固定最后一轮；有效 batch=385、microbatch=8 梯度累积，Adam 1e-3，dropout=0.5。valid 分类曲线仅监测，不按 valid loss 或检索指标挑最好模型。
- **适配边界**：MixedWM38 没有每 die 的缺陷事件计数，不能重建原始密度。优化器、学习率、padding、dropout、初始化和最终 checkpoint 规则等为实现约定，不宣称来自论文。
- **代码依据**：[Nakazawa README](../methods/nakazawa/README.md)。

## 5. WMHD：密度加权的方向性点集匹配

- **论文**：Hsu et al.，*Similarity matching of wafer bin maps for manufacturing intelligence to empower Industry 3.5 for semiconductor manufacturing*，Computers & Industrial Engineering，2020。[DOI](https://doi.org/10.1016/j.cie.2020.106358)。
- **原文实验与数据**：基于真实制造数据模拟、调整的晶圆图；候选库 1,000 张，含 760 张随机模式及 240 张系统模式，包含双缺陷组合。10 张 query 检查位置、大小、旋转、噪声等变化，比较 W0/W1/W2 与是否启用离群惩罚；原文 PI 不是 Precision 或 mAP。
- **本项目流程**：ESRN 八邻域去噪，按晶圆半径归一化坐标，mountain function 计算密度；默认 W2 汇总中心和八邻域九项相对差，O1 对容差内全部候选点取加权 city-block 最小距离，并惩罚未匹配 query 点。保持 query→candidate 方向，以负距离排序。
- **冻结设置**：无训练；mountain_m=0.1、归一晶圆半径匹配容差=0.1、ESRN 阈值=5/8；不抽点近似，不把方向性距离改成对称距离。
- **适配边界**：原文未充分交代旋转对齐和数值参数；当前采用固定 Cartesian 方向，不能声称完整恢复原文旋转预处理。当前低分只代表本实现与适配，不证明原方法在论文数据上无效。
- **代码依据**：[WMHD README](../methods/wmhd/README.md)。

## 6. WaPIRL：与 F 对齐的自监督整图适配

- **论文**：Hyungu Kahng、Seoung Bum Kim，*Self-Supervised Representation Learning for Wafer Bin Map Defect Pattern Classification*，IEEE TSM，34(1):74–86，2021（2020 在线发表）。[DOI](https://doi.org/10.1109/TSM.2020.3038165)、[作者机构记录](https://pure.korea.ac.kr/en/publications/self-supervised-representation-learning-for-wafer-bin-map-defect-/)、[作者代码](https://github.com/hgkahng/WaPIRL)。
- **原文实验与数据**：在 WM-811K 上用无标签图做自监督预训练，再用已有标签微调分类，研究标签不足时的分类效果。原论文不是本项目这套混合缺陷检索协议。
- **本项目流程**：整图缩放至 96×96，三通道为缺陷／缺陷／有效晶圆；ResNet18、stem stride1、h512、128 维线性 projector，原图和直角旋转构成自监督视图。检索直接用归一化 h512 的余弦截断至 [0,1]，不提取区域、不做区域匹配。
- **训练与选模**：SGD，100 epoch、batch256、lr0.01、momentum0.9、weight_decay0.001、cosine；温度0.07、memory EMA0.5、5,000 负样本。最低 valid NCE 选 `best_nce`，已完成运行选中第100轮，NCE=1.811406688，共9,900次更新。
- **适配边界**：模型和训练基元与 F 对齐，原文的后续监督分类微调未加入本次检索。输入通道、增强和检索头是本项目适配，不能叫原论文逐项复现；整图与区域每轮样本单位不同，训练预算也不等同。
- **代码依据**：[WaPIRL README](../methods/wapirl/README.md)。
